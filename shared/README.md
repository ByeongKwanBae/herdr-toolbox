# 공통 코드

여러 mod가 함께 사용하는 로직을 두는 디렉터리입니다. 현재는 공통 코드가 없습니다.

- 재사용하는 모듈이 확인된 뒤 공통 책임을 분리합니다.
- 한 mod의 UI나 개인 설정은 그 mod 내부에 둡니다.
- 가능하면 앱 API와 분리한 순수 로직으로 작성하고 공통 로직 자체를 테스트합니다.
- 공통 코드를 바꾸면 이를 사용하는 모든 모듈의 영향과 검증 결과를 확인합니다.
- GitHub 릴리스에는 모듈 실행에 필요한 공통 코드가 번들에 포함되도록 빌드합니다.

전체 운영 규칙은 [CONTRIBUTING.md](../CONTRIBUTING.md), 모듈 목록은 [README.md](../README.md)를 참고하세요.
