UI 도우미는 일반 객체이며 루트만 View를 상속합니다. Herdr View 생성자는 초기화를 수행하므로
도우미를 new View()로 만든 뒤 init을 중복 호출하면 안 됩니다. 컨텍스트를 보관하지 않고
이벤트·태스크가 받은 cx를 사용합니다. 런타임에서는 Node·DOM·브라우저 타이머를 사용하지 않습니다.

## 저장과 데이터 보존

키는 space-organizer.groups, 최초 스키마는 1입니다. 그룹은 머신 하나에 속하고 Space는 그룹 하나에만 속합니다.
JSON과 shared 값은 unknown에서 검증하며 멤버십은 자체 소유 키로만 조회·설정합니다.
그룹 이름은 NFC, trim, 1–60 코드 포인트, 제어 문자 제외, 같은 머신의 toLowerCase 중복 금지입니다.

각 조작은 최신 값을 다시 읽어 변경합니다. 새 스키마나 잘못된 값은 덮어쓰지 않고 편집을 중단합니다.
초기화·렌더는 그룹을 새로 저장하지 않습니다. checking()이면 모든 쓰기·생성·이동·외부 실행을 차단합니다.
여러 프로세스 사이의 원자적 비교·교환은 제공하지 않습니다.

삭제 정리는 ready 상태에서 1초 이상 간격을 둔 두 관찰이 필요합니다.
loading, unavailable 또는 사라진 머신은 증거를 취소합니다. 정리 직전에도 현재 소속과 존재 여부를 확인합니다.
빈 그룹을 자동으로 지우지 않으며 그룹 삭제는 Space 종료와 연결하지 않습니다.

## 실제 순서와 표시

머신 순서는 호스트 기준을 유지하고, 머신 안에서 그룹 생성 순서 → 그룹 없는 영역으로 배치합니다.
동일 그룹 안에서만 worktree를 부모 아래로 모읍니다. 다른 그룹의 자식은 옮기거나 자동 소속시키지 않습니다.
그룹 순서와 worktree 순서를 별도로 적용하지 않습니다. 이동은 전체 기준 1부터 시작하는 index로 시뮬레이션합니다.

render는 관찰한 실제 순서만 표시합니다. 이동은 별도 태스크에서 한 계획씩 실행하고 echo를 확인합니다.
변경·경합이 생기면 최신 목록으로 재계산하되 같은 조작은 최초 포함 3회, 최소 1초 간격으로 제한합니다.
Space 생성·삭제와 재렌더링은 재시도 예산을 초기화하지 않습니다.
그룹 이름·접힘은 정렬 의도를 바꾸지 않습니다. 명시적 retry-order 또는 새 소속 변경은 새 예산입니다.

수렴 전에는 실제 행과 그룹 레이블을 표시하고, 수렴 후 그룹 헤더 배치를 표시합니다.
접힌 행도 실제 index를 유지하며 레일은 모든 Space를 표시합니다.
펼친 사이드바는 머신 구분선, 들여쓴 폴더 그룹, 구성원 연결선으로 트리를 표시합니다.
구성원 행의 기존 hitbox 안에 절대 위치 가이드를 그려 직접 스크롤 자식 수와 포인터 이벤트 경로를 유지합니다.
선택 배경은 가이드 안쪽 내용에만 적용하며 worktree는 그 안에서 추가로 들여씁니다.
선택 ID가 바뀔 때만 선택 그룹을 펼치므로 현재 Space가 든 그룹의 수동 접힘은 유지됩니다.

## 생성과 메뉴 경계

폴더 선택 전에 동기적으로 예약해 연속 클릭을 제한합니다. 선택을 닫은 뒤 명령 직전에 ID 집합을 기록합니다.
PendingCreation은 토큰·그룹·머신·폴더·기존 ID·시작 시각을 메모리에만 가집니다.
250ms 간격, 최대 5초 내의 유일한 같은 폴더 후보와 현재 그룹을 확인한 뒤 자동 소속합니다.
늦게 깨어난 태스크도 5초 마감을 넘기면 소속시키지 않습니다. 실패·시간 초과에서 재생성하거나 삭제하지 않습니다.
재로딩된 이전 태스크는 컨텍스트 소유권 확인 뒤 호스트 호출을 중단합니다.

메뉴는 불투명 Space/그룹 ID를 props에 전달하고 작업 직전 존재를 확인합니다.
클릭은 안정적인 항목 ID를 사용하므로 비동기 git 조회나 소속 변경으로 인덱스가 바뀌어도 다른 명령을 실행하지 않습니다.
Rename과 Delete Space…는 원본 space.rename/space.close 명령, worktree는 원본 overlay 인자를 유지합니다.
Delete Space…는 확인을 생략하지 않으며 실제 폴더를 삭제하는 명령이 아닙니다. 기본 mod와 탭 바는 편집하지 않습니다.

## 드래그 소속 변경

GroupDrag는 인스턴스 메모리에만 포인터 시작점·Space ID·머신과 현재 드롭 대상을 보관합니다.
5px 미만 이동은 클릭 선택이며, 그룹 헤더와 구성원 행은 같은 머신의 소속 이동 대상입니다.
드래그 중 같은 머신에만 소속 해제 영역을 표시합니다. 빈·접힌 그룹도 대상이며 접힘은 유지합니다.
포인터가 사이드바 밖으로 나가거나 다른 곳을 누르면 취소하고, 드롭 후 항상 제스처를 비웁니다.
드롭 직전 최신 상태와 Space·그룹·머신 ready를 재검증하고 GroupStore에서 다시 읽어 저장합니다.
직접 space.move를 호출하지 않고 기존 그룹·worktree 정렬기에 맡깁니다. 드래그 중 선택 행 자동 스크롤을 억제합니다.
머신 간 이동·임의 순서 변경·스크롤 경계 자동 스크롤은 제공하지 않습니다.

## 검증과 배포 경계

순수 로직·어댑터 테스트와 초기 네이티브 검사, 실제 앱 조작을 구분합니다.
원격·worktree 전체 실행은 샘플 저장소로 확인하며 기존 업무 Space를 종료하지 않습니다.
공유할 결과·제약은 README/CHANGE, 원시 검증 증빙은 Git 제외 artifacts/에 보관합니다.
설치·업데이트·복원과 패키징은 아직 구현하지 않았고, 태그·릴리스·자동 업데이트를 만들지 않습니다.
