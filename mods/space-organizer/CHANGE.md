# 변경 이력

Space Organizer의 실제 추가 및 변경 사항을 기록합니다. 아직 배포하지 않은 내용은 `Unreleased`에 모으고, 릴리스할 때 버전과 배포 날짜를 기록합니다.

## Unreleased

목표 버전은 `v0.0.1`이며 아직 출시하지 않았습니다.

### 2026-11-19 — 원격 폴더 탐색과 생성 (dev.2)

- 원격 머신·원격 그룹의 `+`와 원격 빈 목록 생성 행에 별도 폴더 탐색 팝업을 연결했습니다.
- 홈·상위·하위 폴더, 직접 경로 입력, Windows 드라이브/UNC와 POSIX 루트를 지원합니다. 폴더 목록은 500개로 제한합니다.
- Linux·macOS는 sh, Windows는 PowerShell의 인코딩된 경로 데이터를 사용합니다. 선택 폴더를 재확인한 후 머신과 함께 space.new에 전달합니다.
- 같은 머신·같은 경로의 유일한 새 Space만 확인하고, 원격 그룹에서 시작하면 자동 소속합니다. 기존 로컬 생성 경계와 5초 관찰 제한을 공유합니다.
- 탐색 취소·오류·늦은 응답·팝업 종료·중복 클릭과 잘못된 생성 후보 처리를 추가했습니다. 경로 수정 후에는 Go로 조회해야 생성할 수 있습니다.
- strict 타입 검사·테스트 72개·ESM 빌드·앱 초기 검사 4종을 통과했습니다.
- 실제 WSL에서 탐색·취소·생성·그룹 소속과 새 터미널 cwd를 확인했습니다. Windows PowerShell 조회는 현재 PC에서 실행했습니다. 원격 Windows와 macOS의 전체 실기 흐름은 미검증입니다.

### 2026-11-19 — 트리형 그룹 디자인

- 선택된 트리형 시안을 적용했습니다. 머신 헤더 구분선, 들여쓴 폴더 아이콘과 강조된 그룹 이름으로 계층을 구분합니다.
- 그룹 구성원을 세로 연결선 안에 표시하고 선택 배경은 연결선 안쪽의 Space 행에만 적용합니다.
- 긴 그룹 이름을 말줄임 처리하고 툴팁에 전체 이름을 표시합니다.
- Space별 직접 스크롤 항목 구조와 worktree의 추가 들여쓰기를 유지합니다.
- strict 타입 검사·테스트 49개·ESM 빌드·앱 초기 검사 3종을 통과했습니다. 실제 앱의 로컬·WSL 표시와 접기·드래그를 확인하고 검증 Space 정리 후 기존 그룹·Space 순서·선택을 대조했습니다.

### 2026-11-18 — 드래그 그룹 이동과 닫기 메뉴 보완

- Space 우클릭의 Close를 Delete Space…로 표시합니다. 기존 space.close와 기본 확인창을 사용합니다.
- 로컬·원격 Space를 같은 머신의 빈·접힌 그룹 헤더 또는 구성원 위에 드래그해 소속을 바꿀 수 있습니다.
- 드래그 중 소속 해제 영역, 대상 강조, 원본 행 흐림과 다른 머신 대상 금지 커서를 추가했습니다.
- 5px 미만 이동은 클릭이며, 드롭 직전 Space·그룹·연결 상태를 재확인합니다. 취소·실패 후 제스처를 비웁니다.
- 드래그 중 선택 행의 자동 스크롤로 목록이 튀는 것을 막았습니다. 임의 재정렬과 경계 자동 스크롤은 추가하지 않았습니다.
- 누르기 시점에 상태를 바로 갱신하고, 재렌더·자식 hitbox의 hover 변경은 실제 사이드바 경계 이탈과 구분합니다.
- 드래그 경계·로컬/WSL·빈/접힌 그룹·소속 해제·연결 변경·삭제 경합을 검증하는 테스트 10개를 추가했습니다.
- strict 타입 검사·총 49개 테스트·ESM 빌드·앱 초기 검사 3종을 통과했습니다. 실제 앱에서 로컬·WSL 드래그와 Delete Space 확인 종료를 검증하고 기존 그룹·Space 순서·선택을 복원했습니다.
- 그룹 디자인 시안 3종을 비교 자료로 제공했습니다. 선택된 트리형 적용은 위 2026-11-19 항목에 기록합니다.

### 2026-11-18 — 그룹 관리와 전체 실행 검증

#### 추가

- 머신별 그룹 생성·이름 변경·삭제, 같은 머신의 Space 소속 이동·해제, 접기·상태·개수를 구현했습니다.
- space-organizer.groups/schema 1 검증과 최신 상태 기반 저장을 추가했습니다. 잘못된 값과 새 스키마는 보존하며 기본 목록을 유지합니다.
- ready 상태에서 두 번 관찰한 삭제만 정리하고, 로딩·연결 끊김·사라진 머신의 기록은 보존합니다.
- 그룹과 같은 영역의 worktree를 한 순서 계획으로 통합했습니다. 실제 index를 유지하며 1초 간격, 최초 포함 3회로 자동 적용을 제한합니다.
- 로컬 그룹의 폴더 선택 생성과 안전한 자동 소속, 늦은 후보·시간 초과·그룹 변경 시 취소를 추가했습니다.
- 그룹·Space 메뉴와 입력·삭제 확인을 같은 mod의 오버레이로 제공하고, 기본 Rename·Close·worktree 항목을 함께 유지합니다.

#### 수정

- 실제 메뉴의 스크롤 영역에 높이를 지정하고 긴 목록에서도 사이드바 헤더를 유지했습니다.
- 메뉴 항목을 안정적인 ID로 실행해 비동기 목록 변경으로 다른 명령이 실행되는 것을 막았습니다.
- 렌더에서 이동·상태 저장을 제거하고 관찰·동기화 태스크로 옮겼습니다.

#### 검증 및 상태

- strict 타입 검사, 테스트 39개, ESM 빌드와 초기 앱 검사 3종을 통과했습니다.
- 실제 앱에서 그룹 CRUD·소속·접힘·재로딩 보존·번호 레일·로컬 그룹 자동 소속을 확인했습니다.
- 원격 헤더 생성과 로컬 Windows·원격 Linux 각각의 worktree 생성·기존 체크아웃 열기·삭제를 전체 실행했습니다. 경로·Git 등록·Space 제거와 브랜치 보존을 확인했습니다.
- 테스트 그룹·Space·원격 임시 저장소를 정리하고 기존 Space 집합·상대 순서·업무 화면을 복원했습니다.
- 개발 버전은 0.0.1-dev.1, 최신 배포 버전은 미출시입니다. 설치·복원·배포 도구와 남은 출시 검증은 후속 범위입니다.

### 2026-11-17 — bootstrap 구현

#### 추가

- Node.js 24.22.3, npm 11.19.1, TypeScript strict, esbuild ESM 빌드와 개발 의존성 잠금을 구성했습니다.
- Herdr 0.1.16 SDK 준비·해시 검증과 원본 Spaces 추적용 sdk.lock.json을 추가했습니다.
- 기본 Spaces를 TypeScript로 포팅하고 머신·git 표시, 기본 Space 메뉴와 worktree 대화상자 연결을 유지했습니다.
- Spaces 헤더와 로컬 머신의 생성 버튼에 시스템 폴더 선택을 연결했습니다. 경로를 직접 전달하고 취소·예외·중복 요청과 생성 관찰 시간 초과를 처리합니다.
- 같은 mod를 props.view로 분기하는 개발 상태 메뉴와 대화상자를 추가했습니다.
- 로컬 생성 로직과 앱 어댑터 경계의 Node 테스트 14개를 추가했습니다.
- 검사 중 사용자 상태 쓰기·Space 명령·외부 프로세스 실행을 막고 사이드바·menu·group 초기 렌더 검사 명령을 추가했습니다.
- 명시한 복제 mod에만 성공한 빌드를 반영하는 개발용 동기화·감시 명령과 원본 라이선스 고지를 추가했습니다.

#### 변경

- v0.0.1 설계에 따라 드래그 재정렬을 비활성화하고 클릭 선택을 유지했습니다.
- README의 실행 절차와 검증·기능 상태를 갱신하고 RECIPE 개발 문서를 추가했습니다. 상세 검증 증빙은 Git 제외 artifacts/에 보관합니다.

#### 검증 및 상태

- 타입 검사, 테스트 14개와 ESM 빌드를 통과했습니다. 앱 초기 검사 3종과 실제 UI 조작 결과는 [README](README.md)에서 구분합니다.
- 실제 앱에서 자체 오버레이, 선택 취소·재시도, 한글·공백 경로 생성과 일회용 Space의 기본 조작을 확인했습니다.
- 개발 버전은 0.0.1-dev.0이며 미출시입니다. 그룹 관리, 순서 통합·자동 소속과 배포 도구는 아직 구현하지 않았습니다.
