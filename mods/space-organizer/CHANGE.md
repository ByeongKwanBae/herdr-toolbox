## Unreleased

### 2026-11-17

#### 추가

- 프로젝트 소개, v0.0.1 목표, 개발 환경과 배포 계획을 담은 `README.md`를 작성했습니다.
- 변경 이력을 관리하는 `CHANGE.md`를 추가했습니다.
- 로컬 개발용 v0.0.1 제품 요구사항 `PRD.md`와 구현 명세 `SPEC.md`를 작성했습니다.
- 소스와 테스트를 둘 `src/`, `tests/` 디렉터리를 준비했습니다.

#### 변경

- 단독 저장소에서 준비한 문서를 `herdr-toolbox`의 `mods/space-organizer/` 구조로 이전했습니다.
- 최상위 `.gitignore`에서 모든 모듈의 `PRD.md`, `SPEC.md`를 Git 관리 대상에서 제외하도록 구성했습니다.
- 모듈별 릴리스 태그를 `space-organizer/v0.0.1` 형식으로 정했습니다.

#### 개발 상태

- TypeScript로 개발하고 JavaScript ESM으로 빌드하는 방향을 정했습니다.
- 첫 버전의 초안 범위는 Space 그룹 관리와 로컬 폴더 선택입니다.
- 기능 코드, 빌드 및 테스트 스크립트, 설치 프로그램과 배포 파일은 아직 없습니다.

프로젝트 개요와 현재 계획은 [README.md](README.md)에서 확인할 수 있습니다.
