# 공통 개발 및 배포 도구

저장소 전체에서 사용하는 개발 보조, 모듈 검사와 배포 도구를 두는 디렉터리입니다. 현재는 실행 스크립트가 없습니다.

한 모듈에만 필요한 SDK 준비, 빌드와 설치 스크립트는 해당 모듈 안에 둡니다. 여러 모듈에서 같은 절차를 사용하게 되면 이 디렉터리로 통합합니다.

공통 도구를 추가할 때는 실행 위치, 대상 모듈, 필요한 도구와 실제 검증한 명령을 문서화합니다. 모듈 이름을 지정하지 않은 실행이 사용자의 설치 파일이나 모든 모듈을 임의로 변경하지 않도록 동작 범위를 명확하게 합니다.

전체 운영 규칙은 [CONTRIBUTING.md](../CONTRIBUTING.md), 모듈 목록은 [README.md](../README.md)를 참고하세요.
